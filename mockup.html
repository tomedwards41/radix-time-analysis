How to Import
1
Export from BigTime
Go to BigTime → Reports → Time Reports. Export as CSV. Required columns: Project, Staff Member, Date, Input, N/C, Notes, Labor Rate, Labor Cost
2
Run the import script
# Local D1 (development)
python import_bigtime.py path/to/export.csv --year 2026

# Remote Cloudflare D1 (production)
python import_bigtime.py path/to/export.csv --year 2026 --remote
The script automatically applies the N/C reclassification rules and matches staff against the roster.
3
Import roster (first time or when rates change)
python import_bigtime.py --roster "3.2026 Labor Analysis - PS & R&D.xlsx" --remote
